## 👨‍💻 About Me

I'm a **Flutter Developer** and **Software QA Engineer** focused on building reliable, maintainable, and production-ready applications.

I enjoy working across both development and quality assurance — from designing Flutter features and integrating APIs to validating application behavior through manual and automated testing.

- 📱 Building mobile applications using **Flutter & Dart**
- 🧠 Using **Bloc / Cubit** for scalable state management
- 🔗 Integrating **REST APIs, Firebase, and local databases**
- 🧪 Performing **Web & Mobile testing**
- 🤖 Building web automation using **Selenium WebDriver & Java**
- 📡 Performing API testing using **Postman**
- 🗄️ Using **SQL** for database validation
- 🏗️ Interested in clean architecture and maintainable code
- 🚀 Continuously improving mobile development and software quality skills
